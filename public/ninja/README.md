# Ninja assets

Character walk sprites (`characters/*/walk.png`) and the training-post prop
(`tiles/log_post.png`) are cropped from the **Ninja Adventure Asset Pack** by
Pixel-boy and AAA (https://pixel-boy.itch.io/ninja-adventure-asset-pack),
released under CC0 — no attribution required.

Full source pack lives outside the repo in `assets-src/` (gitignored); only
the files actually used by the app are copied in here.
