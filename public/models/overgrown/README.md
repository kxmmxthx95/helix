# Overgrown city kit (bright cartoon style) — detached prototype

Preview: http://localhost:5555/overgrown-scene.html (fixed camera, stage buttons only; no orbit/zoom).

14 standalone GLBs (see `manifest.json`, `validation.json`): statue-head, building-ivy-a/b/c, shop-awning, van-wrecked, car-wrecked,
stairs-stone, ground-grass, ground-path, pond-small, waterfall-stream, tree-round, bush-round.

- Rebuild: `/Applications/Blender.app/Contents/MacOS/Blender -b --python scripts/ruins-city/build_ruins.py` (source `.blend`: `art/overgrown/overgrown-kit.blend`).
- Blender Z-up, front faces -Y (glTF +Z), metres, embedded 512px PNG textures generated by script (no reference pixels).
- statue-head: original stylization of a giant colossus head (diadem with 7 rays); pivot shifted so the lowest point is y=0
  (head origin sits 2.8 m above the original model centre — the scene uses this to attach the waterfall to the mouth).
- Khronos validator: 14/14, 0 errors, 0 warnings. 77,554 triangles, 21.1 MB total.

Limitations: procedural/faceted forms, repeating textures, flat-coloured glass, no LOD/collision, buildings are boxes with blob ivy,
text "SHOP" uses Blender's default font. Not a match of the reference's painted detail. Not integrated into /map.
